# db-convention.md

# DB Convention

# 테이블 규칙

- 테이블명은 snake_case 사용
- 단수형 사용
- Prefix 사용 지양

## 예시

```text
user
account_transaction
stock_order
```

---

# 컬럼 규칙

- 컬럼명은 snake_case 사용
- PK 컬럼명은 id 사용
- FK 컬럼명은 {table_name}_id 사용

## 예시

```text
user_id
account_id
stock_order_id
```

---

# PK 규칙

- PK는 bigint 사용
- AUTO_INCREMENT 기반 사용

## 예시

```sql
id
bigint generated by default as identity
```

---

# 공통 컬럼 규칙

모든 주요 테이블은 아래 컬럼 사용을 권장합니다.

| 컬럼         | 설명  |
|------------|-----|
| created_at | 생성일 |
| updated_at | 수정일 |

---

# 날짜 타입 규칙

- timestamp 사용
- ISO-8601 기반 처리

---

# 금액 타입 규칙

- 금액은 numeric(18,2) 사용
- float/double 사용 금지

## 예시

```sql
balance
numeric(18,2)
price numeric(18,2)
```

---

# 상태값 규칙

- enum 대신 varchar 저장 권장
- 코드성 데이터는 별도 enum class 관리

## 예시

```text
PENDING
SUCCESS
FAILED
```

---

# 삭제 정책

- 금융 거래 데이터 soft delete 금지
- 실제 삭제 대신 상태값 관리 권장

---

# 인덱스 규칙

- FK 컬럼 index 생성 권장
- created_at index 권장
- 조회 조건 컬럼 index 추가

---

# 감사(Audit) 규칙

금융 거래 테이블은 아래 정보를 저장해야 합니다.

| 컬럼         | 설명       |
|------------|----------|
| trace_id   | 요청 추적 ID |
| created_at | 생성 시간    |
| created_by | 생성 주체    |

---

# 트랜잭션 규칙

- 금융 거래 데이터는 immutable 기반 관리
- UPDATE보다 INSERT 기반 이력 관리 권장

---

# 네이밍 규칙

| 대상          | 규칙                   |
|-------------|----------------------|
| 테이블         | snake_case           |
| 컬럼          | snake_case           |
| index       | idx_{table}_{column} |
| unique key  | uk_{table}_{column}  |
| foreign key | fk_{table}_{target}  |

---

# 예시

```sql
create table account_transaction
(
    id               bigint generated by default as identity primary key,
    account_id       bigint         not null,
    amount           numeric(18, 2) not null,
    transaction_type varchar(30)    not null,
    created_at       timestamp      not null
);
```
