# db-bank-spec.md

# 은행 DB 명세

## 개요

은행 DB는 계좌 및 거래 원장 데이터를 저장하는 핵심 금융 데이터베이스입니다.

금융 원장의 정확성과 불변성 보장을 최우선으로 하며, 외부 네트워크와 분리된 온프레미스 폐쇄망에서 운영합니다.

| 항목 | 내용            |
|----|---------------|
| 위치 | 온프레미스 (폐쇄망)   |
| DB | PostgreSQL    |
| 역할 | 계좌 및 거래 원장 관리 |

---

## 테이블 목록

| 테이블명                | 역할          |
|---------------------|-------------|
| account             | 계좌 기본 정보    |
| account_transaction | 계좌 거래 내역 원장 |
| transfer            | 이체 내역       |
| balance_snapshot    | 일별 잔액 스냅샷   |

---

## 테이블 명세

### account

#### 역할

사용자의 은행 계좌 기본 정보를 관리합니다.

계좌 원장의 최상위 엔티티로, 계좌번호, 종류, 현재 상태를 저장합니다.

#### DDL

```sql
create table account
(
    id             bigint generated by default as identity primary key,
    user_id        bigint       not null,
    account_number varchar(30)  not null,
    account_type   varchar(30)  not null,
    bank_code      varchar(10)  not null,
    currency       varchar(3)   not null default 'KRW',
    status         varchar(30)  not null default 'ACTIVE',
    opened_at      date         not null,
    closed_at      date,
    trace_id       varchar(36)  not null,
    created_at     timestamp    not null,
    created_by     varchar(100) not null
);
```

#### 컬럼 설명

| 컬럼             | 타입           | 설명                            |
|----------------|--------------|-------------------------------|
| id             | bigint       | PK                            |
| user_id        | bigint       | 계좌 소유 사용자 ID                  |
| account_number | varchar(30)  | 계좌번호                          |
| account_type   | varchar(30)  | 계좌 종류                         |
| bank_code      | varchar(10)  | 은행 코드                         |
| currency       | varchar(3)   | 통화 코드 (ISO 4217, 예: KRW, USD) |
| status         | varchar(30)  | 계좌 상태                         |
| opened_at      | date         | 개설일                           |
| closed_at      | date         | 해지일 (해지 시에만 기록)               |
| trace_id       | varchar(36)  | 요청 추적 ID                      |
| created_at     | timestamp    | 생성 시각                         |
| created_by     | varchar(100) | 생성 주체                         |

#### account_type 값

| 값        | 설명     |
|----------|--------|
| CHECKING | 입출금 계좌 |
| SAVINGS  | 적금 계좌  |
| DEPOSIT  | 예금 계좌  |

#### 상태값

| 값         | 설명    |
|-----------|-------|
| ACTIVE    | 정상    |
| SUSPENDED | 일시 정지 |
| CLOSED    | 해지    |

#### 인덱스

| 이름                        | 컬럼             | 설명          |
|---------------------------|----------------|-------------|
| uk_account_account_number | account_number | 계좌번호 유일성 보장 |
| idx_account_user_id       | user_id        | 사용자별 계좌 조회  |
| idx_account_status        | status         | 상태별 조회      |
| idx_account_created_at    | created_at     | 시간순 조회      |

### account_transaction

#### 역할

계좌의 모든 입출금 거래를 원장으로 저장합니다.

단일 이체는 출금 계좌와 입금 계좌 각각 1건씩 총 2건의 레코드로 기록하는 이중 기입(Double-Entry) 방식을 따릅니다.

거래 원장은 절대 삭제하거나 수정하지 않습니다.

#### DDL

```sql
create table account_transaction
(
    id               bigint generated by default as identity primary key,
    account_id       bigint         not null,
    transaction_type varchar(30)    not null,
    direction        varchar(10)    not null,
    amount           numeric(18, 2) not null,
    balance_after    numeric(18, 2) not null,
    currency         varchar(3)     not null default 'KRW',
    reference_id     varchar(100),
    reference_type   varchar(50),
    description      varchar(200),
    transaction_at   timestamp      not null,
    trace_id         varchar(36)    not null,
    created_at       timestamp      not null,
    created_by       varchar(100)   not null
);
```

#### 컬럼 설명

| 컬럼               | 타입            | 설명                              |
|------------------|---------------|---------------------------------|
| id               | bigint        | PK                              |
| account_id       | bigint        | 대상 계좌 ID (account FK)           |
| transaction_type | varchar(30)   | 거래 유형                           |
| direction        | varchar(10)   | 입금/출금 방향                        |
| amount           | numeric(18,2) | 거래 금액 (항상 양수)                   |
| balance_after    | numeric(18,2) | 거래 후 잔액 스냅샷                     |
| currency         | varchar(3)    | 통화 코드                           |
| reference_id     | varchar(100)  | 연관 거래 식별자 (예: transfer_id)      |
| reference_type   | varchar(50)   | 연관 거래 유형 (예: TRANSFER, PAYMENT) |
| description      | varchar(200)  | 거래 메모 또는 적요                     |
| transaction_at   | timestamp     | 실제 거래 발생 시각                     |
| trace_id         | varchar(36)   | 요청 추적 ID                        |
| created_at       | timestamp     | 원장 기록 시각                        |
| created_by       | varchar(100)  | 생성 주체 (서비스명)                    |

#### transaction_type 값

| 값          | 설명    |
|------------|-------|
| TRANSFER   | 계좌 이체 |
| DEPOSIT    | 입금    |
| WITHDRAWAL | 출금    |
| PAYMENT    | 결제    |
| REFUND     | 환불    |
| FEE        | 수수료   |
| INTEREST   | 이자    |

#### direction 값

| 값      | 설명     |
|--------|--------|
| CREDIT | 입금 (+) |
| DEBIT  | 출금 (-) |

#### 인덱스

| 이름                                     | 컬럼             | 설명           |
|----------------------------------------|----------------|--------------|
| idx_account_transaction_account_id     | account_id     | 계좌별 거래 조회    |
| idx_account_transaction_transaction_at | transaction_at | 거래 시각순 조회    |
| idx_account_transaction_reference_id   | reference_id   | 연관 거래 추적     |
| idx_account_transaction_trace_id       | trace_id       | 요청 추적        |
| idx_account_transaction_created_at     | created_at     | 원장 생성 시각순 조회 |

#### 제약

```sql
alter table account_transaction
    add constraint fk_account_transaction_account
        foreign key (account_id) references account (id);

-- 금액은 항상 양수
alter table account_transaction
    add constraint chk_account_transaction_amount
        check (amount > 0);
```

### transfer

#### 역할

계좌 간 이체 정보를 저장합니다.

하나의 이체는 출금 계좌와 입금 계좌의 account_transaction 2건을 생성하며, 이 두 레코드를 transfer로 묶어 관리합니다.

#### DDL

```sql
create table transfer
(
    id                          bigint generated by default as identity primary key,
    from_account_id             bigint         not null,
    to_account_id               bigint         not null,
    amount                      numeric(18, 2) not null,
    currency                    varchar(3)     not null default 'KRW',
    fee                         numeric(18, 2) not null default 0,
    status                      varchar(30)    not null default 'PENDING',
    from_account_transaction_id bigint,
    to_account_transaction_id   bigint,
    requested_at                timestamp      not null,
    completed_at                timestamp,
    trace_id                    varchar(36)    not null,
    created_at                  timestamp      not null,
    created_by                  varchar(100)   not null
);
```

#### 컬럼 설명

| 컬럼                          | 타입            | 설명                    |
|-----------------------------|---------------|-----------------------|
| id                          | bigint        | PK                    |
| from_account_id             | bigint        | 출금 계좌 ID (account FK) |
| to_account_id               | bigint        | 입금 계좌 ID (account FK) |
| amount                      | numeric(18,2) | 이체 금액                 |
| currency                    | varchar(3)    | 통화 코드                 |
| fee                         | numeric(18,2) | 이체 수수료                |
| status                      | varchar(30)   | 이체 처리 상태              |
| from_account_transaction_id | bigint        | 출금 원장 레코드 ID          |
| to_account_transaction_id   | bigint        | 입금 원장 레코드 ID          |
| requested_at                | timestamp     | 이체 요청 시각              |
| completed_at                | timestamp     | 이체 완료 시각              |
| trace_id                    | varchar(36)   | 요청 추적 ID              |
| created_at                  | timestamp     | 생성 시각                 |
| created_by                  | varchar(100)  | 생성 주체                 |

#### 상태값

| 값          | 설명    |
|------------|-------|
| PENDING    | 처리 대기 |
| PROCESSING | 처리 중  |
| COMPLETED  | 완료    |
| FAILED     | 실패    |
| CANCELLED  | 취소    |

#### 인덱스

| 이름                           | 컬럼              | 설명           |
|------------------------------|-----------------|--------------|
| idx_transfer_from_account_id | from_account_id | 출금 계좌별 이체 조회 |
| idx_transfer_to_account_id   | to_account_id   | 입금 계좌별 이체 조회 |
| idx_transfer_status          | status          | 상태별 조회       |
| idx_transfer_requested_at    | requested_at    | 요청 시각순 조회    |
| idx_transfer_trace_id        | trace_id        | 요청 추적        |

#### 제약

```sql
alter table transfer
    add constraint fk_transfer_from_account
        foreign key (from_account_id) references account (id);

alter table transfer
    add constraint fk_transfer_to_account
        foreign key (to_account_id) references account (id);

-- 출금 계좌와 입금 계좌는 달라야 함
alter table transfer
    add constraint chk_transfer_different_accounts
        check (from_account_id <> to_account_id);

-- 금액은 항상 양수
alter table transfer
    add constraint chk_transfer_amount
        check (amount > 0);
```

### balance_snapshot

#### 역할

계좌의 일별 종가 잔액을 스냅샷으로 저장합니다.

실시간 잔액 조회는 account_transaction의 balance_after를 사용하며, 이 테이블은 정산, 대사, 통계 용도로 활용합니다.

#### DDL

```sql
create table balance_snapshot
(
    id            bigint generated by default as identity primary key,
    account_id    bigint         not null,
    snapshot_date date           not null,
    balance       numeric(18, 2) not null,
    currency      varchar(3)     not null default 'KRW',
    trace_id      varchar(36)    not null,
    created_at    timestamp      not null,
    created_by    varchar(100)   not null
);
```

#### 컬럼 설명

| 컬럼            | 타입            | 설명                 |
|---------------|---------------|--------------------|
| id            | bigint        | PK                 |
| account_id    | bigint        | 계좌 ID (account FK) |
| snapshot_date | date          | 스냅샷 기준 날짜          |
| balance       | numeric(18,2) | 해당 일자 종가 잔액        |
| currency      | varchar(3)    | 통화 코드              |
| trace_id      | varchar(36)   | 요청 추적 ID           |
| created_at    | timestamp     | 스냅샷 생성 시각          |
| created_by    | varchar(100)  | 생성 주체 (배치 서비스명)    |

#### 인덱스

| 이름                                 | 컬럼                        | 설명           |
|------------------------------------|---------------------------|--------------|
| uk_balance_snapshot_account_date   | account_id, snapshot_date | 계좌-날짜 유일성 보장 |
| idx_balance_snapshot_account_id    | account_id                | 계좌별 스냅샷 조회   |
| idx_balance_snapshot_snapshot_date | snapshot_date             | 날짜별 조회       |

#### 제약

```sql
alter table balance_snapshot
    add constraint fk_balance_snapshot_account
        foreign key (account_id) references account (id);
```

## 잔액 정합성 규칙

### 이중 기입 원칙

하나의 이체는 반드시 출금(DEBIT)과 입금(CREDIT) 2건의 account_transaction을 생성해야 합니다.

```
이체 발생 시 원장 기록 예시:

[출금 계좌] account_transaction
  direction = DEBIT
  amount    = 100,000
  balance_after = (이전 잔액 - 100,000)

[입금 계좌] account_transaction
  direction = CREDIT
  amount    = 100,000
  balance_after = (이전 잔액 + 100,000)
```

### 잔액 검증

- `balance_after`는 직전 거래의 `balance_after`를 기준으로 계산
- 일별 배치로 `balance_snapshot`과 `account_transaction` 마지막 `balance_after` 대사 수행
- 불일치 시 `reconciliation_result`에 기록

## 운영 규칙

| 항목     | 규칙                                                |
|--------|---------------------------------------------------|
| 데이터 변경 | account_transaction INSERT only, UPDATE/DELETE 금지 |
