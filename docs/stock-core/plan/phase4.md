PHASE 4 — 보유종목 / 수익률 구축

목표:
- 보유 종목 관리
- 평균단가 계산
- 수익률 계산

────────────────────────────────────

4-1. STOCK_HOLDING 구축

기능:
- 보유수량 관리
- 평균단가 관리

────────────────────────────────────

4-2. 매수 로직 구현

평균단가 계산:

(기존매입금액 + 신규매입금액)
/
(기존수량 + 신규수량)

────────────────────────────────────

4-3. 매도 로직 구현

처리:
- 보유수량 감소
- 수량 0 시 holding 제거 가능

────────────────────────────────────

4-4. 보유종목 조회 API 구현

API:
GET /holdings

응답:
- 종목명
- 보유수량
- 평균단가
- 평가금액
- 손익
- 수익률

────────────────────────────────────

4-5. 수익률 API 구현

API:
GET /holdings/returns

────────────────────────────────────

4-6. 수익률 계산 구현

[ 평가금액 ]

현재가 * 보유수량

────────────────────────────────────

[ 미실현손익 ]

평가금액 - 총매입금액

────────────────────────────────────

[ 수익률 ]

손익 / 총매입금액 * 100

────────────────────────────────────
